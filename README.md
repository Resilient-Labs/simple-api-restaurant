## My Solution

**LastCall – Use Everything Up** is a front-end application that helps restaurant staff turn ingredients they already have on hand into meal inspiration.

The application takes an ingredient entered by the user, retrieves relevant meal data through an API, and displays recipe ideas that can help restaurant teams make use of available ingredients before they go to waste.

![LastCall – Use Everything Up](img/lastcall-use-everything-up.png)

## How It's Made

**Tech used:** HTML, CSS, JavaScript, APIs

The application accepts an ingredient through the search interface and makes an API request for relevant meal information. JavaScript processes the returned data and dynamically renders recipe results to the DOM, including useful details and visual content for each meal.

## What I Learned

This project gave me additional practice working with APIs, handling asynchronous JavaScript, processing dynamic user input, extracting useful information from returned API data, and rendering results to the DOM.
