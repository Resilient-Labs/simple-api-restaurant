# 🍽️ Restaurant Menu Search App


The Restaurant Menu Search App is a simple front-end web application designed to help people easily search menu items by food category or ingredient. Users can enter a food category, such as chicken or pasta, and view all menu items that contain that category.

The application uses an external API to retrieve restaurant menu data and display matching items based on the user's search.

## Features
Menu Search: Enter a food category or ingredient, such as chicken.
Filtered Results: Display all menu items that match the entered category.
API Integration: Retrieve restaurant menu information from an external API.
Dynamic Content: Update search results based on user input.
Interactive Interface: Easily search and browse available menu items.

## Tech Stack
Frontend: HTML, CSS, JavaScript
API: External Restaurant Menu API

## Usage
Open the index.html file in your browser.
Enter a food category or ingredient in the search field, such as chicken.
Submit your search.
View all menu items that contain the selected category or ingredient.
Search another category to explore additional menu items!
